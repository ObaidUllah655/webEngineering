Fetch API - Data Retrieval

Fetching from JSONPlaceholder and displaying the first 5 post titles

JavaScript Code

// Fetch data from the public API
fetch("https://jsonplaceholder.typicode.com/posts")
  .then(response => {
    if (!response.ok) {
      throw new Error("Network response was not ok: " + response.status);
    }
    return response.json();         // parse JSON
  })
  .then(posts => {
    // Get only the first 5 posts
    const firstFive = posts.slice(0, 5);

    // Display each post title
    firstFive.forEach((post, index) => {
      console.log(`${index + 1}. ${post.title}`);
    });
  })
  .catch(error => {
    console.error("Fetch Error:", error.message);
  });
