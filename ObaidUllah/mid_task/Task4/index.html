Async Programming and Error Handling

Fetch API with .then() / .catch() - Successful and Failed requests

JavaScript Code Pattern

// Async fetch with .then() and .catch()
fetch(url)
  .then(response => {
    if (!response.ok) throw new Error("HTTP Error: " + response.status);
    return response.json();
  })
  .then(data => {
    // SUCCESS: display the retrieved data
    displayUsers(data);
  })
  .catch(error => {
    // FAILED: handle the error gracefully
    console.error("Fetch failed:", error.message);
  });
